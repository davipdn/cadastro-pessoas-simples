# Projeto: cadastro-pessoas-simples

Pequeno projeto Java de console com uma única classe para estudo.

## Funcionalidades

- Mostra um menu com 3 opções: adicionar pessoa, ver lista de pessoas e sair.
- Cadastra pessoas apenas pelo NOME (não pede idade nem telefone).
- Guarda os nomes em um array de 10 posições.
- Já começa com 3 pessoas cadastradas: João, Davi e Maria.
- A listagem mostra a posição e o nome de cada pessoa.
- Os dados ficam só na memória e somem ao fechar o programa.
- Ao adicionar uma pessoa, o programa pergunta "Deseja adicionar mais pessoas? [S/N]": responda S para continuar adicionando ou N para voltar ao menu.

## Conceitos praticados

- arrays, switch, while, for, if/else e Scanner.

## Como rodar

- Abra o projeto no IntelliJ com JDK 21 e execute a classe `CadastroPessoasSimples` (arquivo `src/CadastroPessoasSimples.java`).
